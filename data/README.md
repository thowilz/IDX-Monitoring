# data/

## taxonomy_catalog_baseline.xlsx  (you provide)
The IHSG sector/industry taxonomy. Required columns (case-insensitive):

| column        | meaning                                  | example |
|---------------|------------------------------------------|---------|
| `sektor`      | human sector label                       | Keuangan |
| `industri`    | industry code used in transmission maps  | G21 |
| `kode_emiten` | ticker / emiten code                     | BBRI |

Drop the real workbook here as `taxonomy_catalog_baseline.xlsx`. Until then the
loader falls back to `taxonomy_catalog_baseline.sample.csv` (a small stub with
the industry codes the two reference modules reference) so the system runs and
the dashboard can validate transmission codes. A `.csv` of the same shape named
`taxonomy_catalog_baseline.csv` is also accepted.

The taxonomy is used to **validate** module transmission maps (do the claimed
industry codes exist? are emiten in the right industry?). If absent, modules
still run; transmission codes are shown unvalidated rather than invented.
